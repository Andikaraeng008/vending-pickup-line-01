One pickup line a vending machine would use on a passing human.

> You must be exact change, because you fit perfectly and I never want to give you back.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes the entry to `/output/entry.txt`.
